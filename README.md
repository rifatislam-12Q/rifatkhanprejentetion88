## 📌 ওভারভিউ (Overview)

**Green Shop . Com** হলো একটি আধুনিক, ফুললি রেসপনসিভ ও ইন্টারেক্টিভ ৭-স্লাইড সমৃদ্ধ বিজনেস প্রেজেন্টেশন ও ডিজিটাল ই-কমার্স ইকোসিস্টেম। এতে গ্রিন শপের ব্যবসায়িক মডেল, ডেলিভারি লজিস্টিকস, প্ল্যাটফর্ম ফিচার, বিশ্বাসযোগ্যতা, গ্লোবাল মেরিটাইম হাব সম্প্রসারণ, জাতীয় অর্থনৈতিক অবদান এবং বাংলাদেশকে কেন্দ্র করে বৈশ্বিক বাণিজ্য নিয়ন্ত্রণ কৌশল অত্যন্ত প্রফেশনাল ও ডাইনামিক ভিজ্যুয়ালসহ তুলে ধরা হয়েছে।

## ✨ প্রধান বৈশিষ্ঠ্যসমূহ (Key Features)

- 📱 **১০০% ফুললি রেসপনসিভ (Fully Responsive)**: মোবাইল, ট্যাবলেট, ল্যাপটপ এবং ৪K আল্ট্রাওয়াইড স্ক্রিনে নিখুঁত ডিসপ্লে।
- 🎨 **থিম্যাটিক কালার ও আর্টওয়ার্ক**: প্রতিটি স্লাইডের টেক্সট ও বিষয়ের সাথে সামঞ্জস্যপূর্ণ ব্যাকগ্রাউন্ড ও কাস্টম ভেক্টর চিত্র।
- 🚛 **পরিশীলিত ও সোজা ডেলিভারি ট্রাক**: নিখুঁত অ্যারোডাইনামিক কেবিন, ফরোয়ার্ড এলইডি হেডলাইট বিম এবং গ্রিন শপ ব্রান্ডিং।
- 🕹️ **ইন্টারেক্টিভ স্লাইড কন্ট্রোলার**: ফ্লোটিং কন্ট্রোলার, কীবোর্ড অ্যারো কী (`ArrowLeft`, `ArrowRight`) এবং স্ক্রোল নেভিগেশন।
- ⚡ **দ্রুত লোডিং ও হাই পারফরম্যান্স**: Vite এবং React 19 আর্কিটেকচার সমৃদ্ধ অপ্টিমাইজড বান্ডেল সাইজ।

## 💻 লোকাল ডেভেলপমেন্ট রান করার নিয়ম (Getting Started)

### ১. রিপোসিটরি ক্লোন বা ফোল্ডারে প্রবেশ করুন:
```bash
git clone <YOUR_REPOSITORY_URL>
cd green-shop-platform
```

### ২. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

### ৩. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```
ব্রাউজারে ওপেন করুন: `http://localhost:3000`

### ৪. প্রোডাকশন বিল্ড তৈরি করতে:
```bash
npm run build
```

## 🐙 গিটহাবে পুশ করার সম্পূর্ণ নির্দেশিকা (GitHub Push Guide)

আপনি যদি এই প্রজেক্টটি আপনার নিজের GitHub একাউন্টে পুশ করতে চান, নিচের ধাপগুলো অনুসরণ করুন:

### ধাপ ১: গিটহাবে একটি নতুন রিপোজিটরি তৈরি করুন
1. [GitHub](https://github.com/) এ গিয়ে লগইন করুন।
2. ডানদিকের উপরে **+** আইকন থেকে **New repository** সিলেক্ট করুন।
3. রিপোজিটরির নাম দিন (যেমন: `green-shop-platform` বা `green-shop-com`)।
4. **Public** বা **Private** নির্বাচন করুন।
5. "Initialize this repository with a README" টিকচিহ্ন **দেবেন না** (কারণ ইতিমধ্যে README ফাইল তৈরি করা আছে)।
6. **Create repository** বাটনে ক্লিক করুন।

### ধাপ ২: টার্মিনালে নিচের কমান্ডগুলো রান করুন

```bash
# ১. গিট রিপোজিটরি ইনিশিয়ালাইজ করুন (প্রজেক্টে ইতিমধ্যে ইনিশিয়ালাইজ করা আছে)
git init

# ২. সব ফাইল স্টেজিং এরিয়ায় যুক্ত করুন
git add .

# ৩. প্রথম কমিট সম্পন্ন করুন
git commit -m "feat: complete Green Shop 7-slide enterprise platform"

# ৪. মেইন ব্রাঞ্চ নির্ধারণ করুন
git branch -M main

# ৫. আপনার গিটহাব রিপোসিটরির লিঙ্ক অ্যাড করুন (YOUR_USERNAME ও YOUR_REPO এর জায়গায় আপনার তথ্য দিন)
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git

# ৬. গিটহাবে পুশ করুন
git push -u origin main
```

> **টিপস**: পরবর্তীতে কোনো ফাইল পরিবর্তন করলে শুধুমাত্র এই তিনটি কমান্ড রান করলেই গিটহাবে আপডেট হয়ে যাবে:
> ```bash
> git add .
> git commit -m "update: your message"
> git push
> ```

## 🌐 ডেপ্লয়মেন্ট (Deployment)

এই প্রজেক্টটি যেকোনো স্ট্যাটিক হোস্টিং প্ল্যাটফর্মে মাত্র ১ ক্লিকে ডেপ্লয় করা যায়:

- **Vercel**: GitHub কানেক্ট করে `Import` দিলেই সাথে সাথে লাইভ হয়ে যাবে (Build command: `npm run build`, Output directory: `dist`)।
- **Netlify**: GitHub রিপো লিঙ্ক করে Deploy সাইটে ক্লিক করুন।
- **Cloudflare Pages**: Connect to Git এবং Build Settings এ `Vite` সিলেক্ট করুন।
